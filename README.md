# testForCursorDesign

Minimal **Expo + React Native** app containing a mobile screen that lists crypto tokens and their current USD values.

## Run

```bash
npm install
npx expo start
```

Then scan the QR code in **Expo Go** (iOS/Android) or run an emulator.

## What’s included

- **Token list screen**: `src/screens/TokenListScreen.tsx`
- **Live prices**: fetched from CoinGecko `simple/price` (with a small offline fallback)
